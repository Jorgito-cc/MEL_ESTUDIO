# 📸 MEL STUDIO

Sistema de gestión visual y reservas para servicios fotográficos profesionales.  
Presenta un catálogo visual impactante y permite a los clientes agendar sesiones personalizadas según paquetes, horarios y estilos fotográficos.

---

## 🖥️ Tipo de sistema

| Característica          | Descripción                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| Web App (Landing + Portafolio) | Presentación de servicios fotográficos clasificados por categoría visual |
| Sistema de reservas     | Formulario de contacto con selección de horarios, paquetes y detalles personalizados |
| Responsive multipantalla| Interfaz adaptada para dispositivos móviles y escritorio, optimizada para UX |

---

## ⚙️ Tecnologías utilizadas

- **React.js** (v18+)
- **CSS3** con **metodología BEM**
- **React Router DOM** para navegación
- **Hooks API** para manejo de estado
- **Responsive Design** con media queries
- **Vite** como entorno de desarrollo (opcional)
